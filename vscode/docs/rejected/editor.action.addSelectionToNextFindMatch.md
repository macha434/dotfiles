# editor.action.addSelectionToNextFindMatch

## 検討していた内容

既定の `ctrl+d` (次の一致を選択範囲に追加していくマルチカーソル操作) は
`keybindings.json` のサイドバープレフィックス (`ctrl+d` = サイドバー操作) に
上書きされて使えなくなっている。代わりに `ctrl+a d` などへ振り直す案を検討した。

## 不採用の理由

- シンボル(変数・関数)の一括変更は `<space> r` (`editor.action.rename`, Vim
  Normal モード) が言語サーバーの意味解析付きでカバーしており、そちらで
  十分。
- このコマンドが得意とする「一部の一致箇所だけ選んで編集する」という
  部分適用のユースケース自体が、実際の作業で必要になったことがない。
- 言語サーバーが効かないファイル (Markdown, 設定ファイル等) での一括置換は
  Vim の `:s` (substitute) コマンドで足りる。

## 根拠

本人の作業実態による判断(検討時点で部分適用の必要性なし)。
